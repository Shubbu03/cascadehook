The project API operates on an existing project. Create your account,
organization, and project in the dashboard before using these endpoints.

## Before your first request

Read [authentication and project identity](/docs/api/authentication), then
[errors and pagination](/docs/api/errors-pagination). Every request goes to
the Go API origin, which may differ from this documentation site's address.

## OpenAPI

The reference is generated from the same contract served at
[/openapi.json](/openapi.json). Its API server address comes from the docs
deployment configuration. If that address is unavailable, the downloadable
schema returns `503` rather than substituting the documentation host.

Code samples with `YOUR_API_HOST` or `YOUR_PROJECT_API_KEY` contain placeholders.
Replace them with your configured API origin and a locally stored project key.
