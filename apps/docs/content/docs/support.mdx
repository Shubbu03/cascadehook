title: Support
description: Get help with Cascadehook integrations, deliveries, and account access.
---

Email [support@mail.cascadehook.com](mailto:support@mail.cascadehook.com) for help with integration, a delivery, or account access. Include your organization/project ID and any relevant event/delivery ID. Leave out API keys, signing secrets, passwords, and sensitive payloads.

Before writing, check the [quickstart](/docs/quickstart) or [troubleshooting guide](/docs/troubleshooting).

Support is provided by the developer. There is no guaranteed response time or uptime SLA.
