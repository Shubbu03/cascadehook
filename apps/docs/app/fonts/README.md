# IBM Plex fonts

Self-hosted Latin fonts loaded with `next/font/local`:

- IBM Plex Sans: variable weights 100–700.
- IBM Plex Mono: weights 400 and 500.

Source: [Google Fonts Sans](https://github.com/google/fonts/tree/main/ofl/ibmplexsans)
and [Mono](https://github.com/google/fonts/tree/main/ofl/ibmplexmono).
