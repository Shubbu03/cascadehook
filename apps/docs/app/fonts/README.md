# IBM Plex fonts

Self-hosted Latin web fonts, retrieved on 2026-10-23 from Google Fonts.
The original SIL Open Font License files are included alongside the assets.

- IBM Plex Sans variable, weights 100–700, Google Fonts version 23.
- IBM Plex Mono regular and medium, Google Fonts version 20.

Sources:

- https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@400;500&family=IBM+Plex+Sans:wght@100..700&display=swap
- https://github.com/google/fonts/tree/main/ofl/ibmplexsans
- https://github.com/google/fonts/tree/main/ofl/ibmplexmono
- https://github.com/IBM/plex

The app loads these through Next.js's local-font integration. Builds and browsers
do not need to request fonts from Google.
