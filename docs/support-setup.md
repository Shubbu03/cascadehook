# Support and policies

The verified receiving inbox is **support@mail.cascadehook.com**. Read and reply through Resend Inboxes; no receiving webhook is needed for the hosted inbox. Forwarding to a personal mailbox is a separate Resend setting.

Application invitation emails use this address as their default Reply-To. `EMAIL_REPLY_TO` can override it on the API and worker. Keep `EMAIL_FROM` on the verified sending domain. The deployment template passes the Reply-To to both services.

Public routes: `/support`, `/terms`, and `/privacy`. Support links are available in the landing page, docs, and dashboard. The policies describe the current free service, without subscription or refund promises.

Review the public policies against the final operator/legal identity before launch. Cascadehook is described as independently operated from India, without claiming a registered company name.
